## 🌟 Key Highlights & Innovations

### 1. 🔴 Cyber-Luxury Red & Black Design System
- Deep obsidian and charcoal physical backdrops accented with glowing neon crimson (`#ff1e42`) and electric amber.
- **Settings Drawer (⚙)**: Live real-time switcher between:
  - `cyber-crimson`: Neon red scanlines and deep obsidian pedestals.
  - `stealth-obsidian`: Monochrome platinum and carbon stealth styling.
  - `classic-atelier`: Warm heirloom paper and brass tones.
- Dynamic 3D motion intensity controls, glowing aura toggles, and synthesized tactile sound switches.

### 2. 🧩 Interactive 3D Exploded-View Blueprint
- Built with **Three.js** and **React Three Fiber**.
- Toggle the **"Explode Blueprint"** control in the 3D Atelier stage to smoothly disengage:
  - Optical lenses along the Z-axis with anti-reflective coating sheens.
  - Hand-beveled bridge and beta-titanium core wires.
  - Temple arms and micro-hinges.
  - Contoured silicone nose pads.
- Floating technical HUD annotations and holographic metric tags call out exact millimetre tolerances in 3D space.

### 3. ✍️ 3D Customizer & Dynamic Laser Monogram Engraving
- 4 Cyber-Luxury frame finishes:
  - **Crimson Titanium** (Electropolished aviation-grade red titanium)
  - **Matte Carbon Fiber** (Twill weave structural composite)
  - **Brushed Obsidian** (PVD-coated scratch-resistant dark metal)
  - **Damascus Steel** (Folded artisan layered steel)
- **Live Laser Engraving**: Type your name or monogram (e.g. `GANESH REDDY · 001`), and watch an in-memory 512×96 canvas texture dynamically laser-etched onto the inner left temple arm in 3D.

### 4. 🪞 Real-Time Webcam Virtual Try-On (AR Mirror)
- Turn on your camera directly within the 3D studio to overlay virtual eyewear onto your live video feed.
- Cybernetic facial alignment reticles, interactive scale/bridge/height sliders, and crimson reflection glare.
- Instant high-resolution portrait snapshot capture and download.

### 5. 🎙️ Voice-Enabled AI Optical Stylist & Face Matcher
- **Speech Recognition** (microphone voice input) and **Speech Synthesis** (natural voice audio response).
- **Interactive 3-Step Quiz**: Analyzes facial geometry (*Oval, Round, Square, Heart*), daily lighting environment, and aesthetic preference to match the ideal frame and automatically load it into the 3D stage.

### 6. ⚖️ Quick-Compare 3D Split Stage
- Side-by-side synchronized 3D rotation comparing two frames simultaneously.
- Technical blueprint matrix comparing bridge width, lens diameter, frame weight, and prescription compatibility.

### 7. 🇮🇳 Indian Heritage & International Collections
- **Indian Heritage Frames**:
  - `Arya Rectangle` (Madras acetate with sculpted bevel temples)
  - `Ashoka Circle` (Pure scholarly beta-titanium wire circle)
  - `Ganga Oval` (Translucent river crystal contour)
  - `Swaraj Round` (Mid-century panto with keyhole bridge)
  - `Bombay Retro` (Classic browline with golden sun amber)
  - `Garuda Aviator` (Aerospace double brow bar in burnished gold)
- **International Archive Frames**: *Aurelia, Meridian, Noor, Atlas, Vale, Solstice, Lyra, Kronos, Zephyr, Paloma*.
- **Interactive Live Swatch Switching**: Tap any finish swatch dot under *"Finishes"* on any card to watch that frame's preview silhouette dynamically shift color in real-time.

### 8. 🔬 4 Precision Lens Formulations
- **Anti-Glare (Anti-Reflective) Lenses**: Green-spectrum reflection cancellation.
- **Blue-Cut Filter Lenses**: 420 nm high-energy digital light absorption.
- **Photochromic (Transitions) Lenses**: Molecular silver halide UV-adaptive darkening.
- **High-Index 1.74 Lenses**: Ultra-thin compression for strong prescriptions.

### 9. 🔶 Cyber-Orange Visit Section & Private Fitting Popup Window
- Stunning cyber-orange footer banner with glowing *"Bring your curiosity."* typography.
- **Private Fitting Reservation Modal**:
  - Takes client details (*Full Name, Email, Phone/WhatsApp*).

### 10. 🛒 Dedicated E-Commerce Checkout & Patron Bag

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/GANESHREDDY-07/INTERNENT-PROGRAMING.git
cd INTERNENT-PROGRAMING
npm install
```

### 2. Launch Development Server
```bash
npm run dev
```

Visit **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🛠️ Tech Stack & Architecture

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript (Strict Mode)
- **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Sound Effects**: Synthesized Web Audio API Oscillators (zero external audio asset dependencies)
- **Voice AI**: Web Speech API (`SpeechRecognition` & `SpeechSynthesis`)
- **Camera AR**: HTML5 `MediaDevices.getUserMedia()`
- **Styling**: Vanilla CSS Modules, CSS Variables, Hardware-Accelerated Transforms
